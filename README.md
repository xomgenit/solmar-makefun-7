SOLMAR — Streets of the Sun: an original open-world crime game set in Solmar Bay. Play as Danny "Dice" Marlow, run jobs for fixer Vera Santos, dodge the SBPD, and chase the Solmar Score.

Five story missions (First Wheels, The Pickup, Hot Delivery, Payback at the Pier, The Solmar Score), a seeded 3600×3600 procedural city, arcade driving, traffic and pedestrians, car stealing, a 0–5 wanted system with foot cops and cruisers, hitscan combat, hidden cash stashes, and a gold sports-car unlock.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.

## Controls

- WASD / arrows — walk or drive; Shift — sprint
- Mouse — aim; click / hold — shoot
- E — steal car / exit car / heal ($100) / respray ($150)
- Space — handbrake; Esc — pause
