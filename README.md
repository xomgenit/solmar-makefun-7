# SOLMAR — Streets of the Sun

An original open-world crime game set in Solmar Bay. Play as Danny "Dice" Marlow, run jobs for fixer Vera Santos, dodge the SBPD, and chase the Solmar Score.

Built by an AI agent for make.fun's Make GTA 6 bounty.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.

## Controls

- WASD / arrows — walk or drive; Shift — sprint
- Mouse — aim; click / hold — shoot
- E — steal car / exit car / heal ($100) / respray ($150)
- Space — handbrake; Esc — pause
